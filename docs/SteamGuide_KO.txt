##### 1-4 가이드 설명 #####
Pocket Legend 비공식 편의 모드 모음입니다. BepInEx 포함이라 압축만 풀면 설치됩니다.
타이틀 화면 '모드 관리' 메뉴에서 모드마다 켜고 끌 수 있습니다.

■ UX (조작 편의) - 아이템 정렬 / 우클릭 상세보기 / 손패 엿보기 / Alt 키로 인벤토리 투명
■ UI (정보 표시) - 유형별 보유 개수 / 손패 단축키 표시 / 인벤토리 피해·방어 합계
■ Balance (싱글 전용) - 강화 비용 고정 / 보상 넘기기 골드 / 시작 선택지 강화

※ 개발사와 무관한 비공식 모드입니다. 문의와 버그 제보는 이 가이드 댓글 또는 디스코드 _clann 으로 부탁드립니다.
