[h1]설치[/h1]
[olist]
[*]Steam 라이브러리에서 Pocket Legend 우클릭 → 관리 → 로컬 파일 보기
[*]열린 폴더(PocketLegend.exe 가 있는 곳)에 zip 내용물을 그대로 압축 풀기
- All-in-One: 이 zip 하나만 풀면 끝
- 골라서 설치: Base 를 먼저 풀고, 원하는 묶음(UX / UI / Balance)을 같은 폴더에 이어서 풀기
[*]게임 실행 → 타이틀 화면 '게임종료' 위의 [b]모드 관리[/b] 메뉴에서 모드별로 켜고 끄기
[/olist]

[h1]제거[/h1]
[list]
[*]모드 하나만: 게임 폴더의 BepInEx\plugins 에서 해당 PocketLegend.*.dll 삭제 (또는 '모드 관리'에서 OFF)
[*]전부: 게임 폴더의 winhttp.dll 삭제 (BepInEx 폴더까지 지우면 완전 제거)
[/list]

[h1]포함된 모드[/h1]
모드 관리 메뉴에는 [b]UX_ / UI_ / BAL_[/b] 분류와 한국어 이름으로 표시됩니다. (게임 언어가 한국어가 아니면 영어)

[h2]편의 모드 (UX) - 조작을 편하게[/h2]
[list]
[*][b]Item Sort[/b] (UX_아이템 정렬) - 아이템 메뉴, 아이템 선택 창, 전투 더미에 획득순/유형별/이름순/강화순 정렬 버튼
[*][b]Always Show Item Info[/b] (UX_우클릭 상세보기) - 원래 우클릭이 안 되던 선택 창, 이벤트 선택지의 아이템 이름에서도 우클릭으로 상세보기 (전투 인벤토리의 우클릭 사용은 그대로)
[*][b]Peek Hand Info[/b] (UX_손패 엿보기) - '꺼낼 아이템을 선택하세요' 창을 접어두면 손패에 마우스를 올려 정보 확인 (보기 전용)
[*][b]Inventory Fit[/b] (UX_인벤토리 맞춤) - Alt 키로 전투 인벤토리를 반투명하게 해서 가려진 유물·캐릭터 보기. '나의 인벤토리' 화면에서 누르고 있는 동안 / 누를 때마다 전환 선택
[/list]

[h2]정보 표시 모드 (UI) - 화면에 정보를 더 보여 줌[/h2]
[list]
[*][b]Item Type Count[/b] (UI_유형별 개수) - 오른쪽 위 '아이템' 아이콘 아래에 무기/방어구/스킬/귀속 보유 수 2x2 표, 아이콘 오른쪽 아래에 총 보유 개수
[*][b]Show Card Shortcut[/b] (UI_단축키 표시) - 전투 중 손패 위에 숫자 단축키(1~0), 턴 종료 버튼 위에 손패 수 / 10
[*][b]Total InvenInfo[/b] (UI_인벤토리 합계) - 전투 인벤토리에서 지금 사용 가능한 아이템 기준 총/최대 피해·방어. 고고는 마력, 스택은 일월경·빈칸까지 (위치: 인벤토리 아래 / 캐릭터 머리 위)
[/list]

[h2]밸런스 변경 모드 (BAL) - 싱글 전용[/h2]
협동 플레이 중에는 자동으로 적용되지 않습니다. 원하지 않으면 '모드 관리'에서 꺼 주세요.
[list]
[*][b]Fixed Enhance Cost[/b] (BAL_강화 비용 고정) - 대장간 강화 비용이 등급과 관계없이 강화석 1개
[*][b]Better Card Skip[/b] (BAL_보상 넘기기) - 전투 승리 보상의 '카드 획득', '인벤토리 조각' 옆 '보상 넘기기 (+2)' 버튼
[*][b]Better Start Choices[/b] (BAL_시작 선택지 강화) - 시작 선택지에 '무작위 일반 유물 받기' 추가, 아이템 보상·인벤토리 조각을 희귀 등급으로
[/list]

[h2]공통 (Base 에 포함)[/h2]
[list]
[*][b]Mod Switch[/b] (모드 관리) - 타이틀 화면 '게임종료' 위의 '모드 관리' 메뉴에서 모드별 ON/OFF와 세부 옵션
[/list]

[h1]설정 변경[/h1]
대부분의 설정은 '모드 관리' 메뉴의 세부 옵션(- 로 시작하는 줄)에서 바꿀 수 있습니다.
그 밖의 값은 게임을 한 번 실행하면 생기는 BepInEx\config\pocketlegend.*.cfg 파일을, 게임을 끈 상태에서 메모장으로 열어 바꾸면 됩니다.
예) 보상 넘기기 골드: pocketlegend.bettercardskip.cfg 의 SkipGold / 강화석 개수: pocketlegend.enhancecost.cfg 의 FixedCost
